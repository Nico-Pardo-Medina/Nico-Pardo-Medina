## Projects

### Machine Learning & Computer Vision

**[setorium](https://github.com/Nico-Pardo-Medina/setorium)** — Mushroom species identifier built with MobileNetV2 transfer learning and Flask. Upload a photo, get the top-2 predictions with confidence scores and edibility information (edible / toxic / deadly). Dataset collected via a custom Selenium scraper. Deployed on Heroku. Built as a team project.

**[owl-nest-watcher](https://github.com/Nico-Pardo-Medina/owl-nest-watcher)** — Desktop GUI tool that analyses batches of nest-camera videos and produces timestamped activity reports. Built with OpenCV and Tkinter. Originally made for wildlife biologists to avoid watching hours of owl footage manually — works for any motion detection scenario.

### Backend & APIs

**[car-booking-api](https://github.com/Nico-Pardo-Medina/car-booking-api)** — REST API for car bookings built with FastAPI. Layered architecture (routers / services / models), native Pydantic validation with `datetime.date` fields, 8-test pytest suite, and Docker. One of my first backend projects.

### Tools & Automation

**[replicator](https://github.com/Nico-Pardo-Medina/replicator)** — One-way folder sync CLI built in pure Python stdlib. Mirrors a source directory into a destination with dry-run mode, exclusion patterns, optional repeat interval, and MD5 checksum verification. Built before I discovered rsync — it worked.

### Other

**[odoo-helpdesk-module](https://github.com/Nico-Pardo-Medina/odoo-helpdesk-module)** — Custom Odoo 16 module adding a support ticket system with a `new → in progress → resolved` state machine. Includes a Docker Compose setup for local development.
